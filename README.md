🔫 Weapon Detection Flask
📌 Présentation
Weapon Detection Flask est une application web développée avec Python et Flask permettant de détecter automatiquement la présence d'armes à l'aide de techniques de vision par ordinateur et d'intelligence artificielle.
Le projet utilise notamment YOLO et OpenCV pour l'analyse des images et des flux vidéo.
🎯 Objectif
L'objectif de ce projet est de mettre en place un système capable d'assister la surveillance en détectant automatiquement la présence potentielle d'une arme dans une image ou un flux vidéo.
⚙️ Technologies utilisées
🐍 Python
🌐 Flask
👁️ OpenCV
🤖 YOLO
🗄️ SQLite
📡 MQTT
HTML / CSS / JavaScript
✨ Fonctionnalités
Détection automatique d'armes
Analyse d'images et/ou de flux vidéo
Interface web avec Flask
Utilisation d'un modèle YOLO entraîné pour la détection
Enregistrement des événements détectés
Gestion d'une base de données
Système d'alerte
Interface web responsive
